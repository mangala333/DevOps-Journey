What is DevOps?
DevOps is a culure for delivering to the end user faster.
Devops is used to deploy the code to server faster with automation, good quality, Monitoring and Testing in place using CI/CD.

Why DevOps?
Before DevOps existed deployed from the repository to server was taking lot of efforts, roles, time to deploy in the server and take that to Customer.
As it involved server to be created. System Admin, BRE and Server Admins to work together for number of days to get the application deployed to server.
